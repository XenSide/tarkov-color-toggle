# Tarkov - Stereo Bites EQ plus HD58X compensation
#
# Identical to tarkov.txt with exactly one filter added: a low shelf to offset the
# HD58X Jubilee's bass lift (roughly +5 dB below ~150 Hz versus neutral). The
# source settings were tuned on flatter headphones (HD 560S, DT 900 Pro X, PC38X),
# which did not need that correction.
#
# Because this differs from the baseline by one filter only, A/B against
# tarkov.txt tells you whether that correction actually helps on your ears.

Filter: ON HPQ Fc 100 Hz Q 0.8
Filter: ON LS 6dB Fc 150 Hz Gain -3 dB
Filter: ON PK Fc 550 Hz Gain -2 dB Q 1.1
Filter: ON PK Fc 6000 Hz Gain -3 dB Q 5
Filter: ON HS Fc 10000 Hz Gain 3 dB
